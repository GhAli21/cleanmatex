# CleanMateX i18n Guide

Use folder-based locale catalogs under `web-admin/messages/en/**` and `web-admin/messages/ar/**`.

## Rules

- Check `docs/dev/i18n_docs/GLOSSARY.md` first, for new keys **and** when editing an existing key's
  text — reuse its approved EN/AR term for the concept (e.g. "Organization" / "المنشأة" for a tenant,
  never "Tenant" / "مستأجر").
- Search existing keys before adding new ones; avoid duplicate keys as much as possible, even across namespaces.
- Reuse `common.*` for generic UI strings.
- Keep the locale file tree and leaf-key set aligned across `en` and `ar`.
- A namespace may be a file or a folder, never both.
- Use `index.json` inside a namespace folder when root keys must stay at that namespace level.
- Do not import locale JSON directly in components.
- Validate with `npm run check:i18n`.

## Example structure

```text
web-admin/messages/
  en/
    common.json
    orders/index.json
    orders/detail.json
  ar/
    common.json
    orders/index.json
    orders/detail.json
```
