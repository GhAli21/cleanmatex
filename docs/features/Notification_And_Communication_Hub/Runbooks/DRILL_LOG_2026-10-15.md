## Defect found and fixed by the drill

**Circuit flapping (runbook 09).** After a half-open circuit closed on a successful probe, the failures that had opened it were still inside the 10-minute health window, so the next evaluation (one minute later) saw the same failure rate and opened the circuit again. Real traffic would have kept being refused after the provider recovered, for up to the length of the window, and an alert would fire each time.
**Fix:** migration `0628_ntf_breaker_evidence_since_close.sql` (new read function used only by the breaker; a closed circuit judges only commands since its last transition) and `ProviderControlRepository.breakerEvidence` (falls back to the old function while 0628 is not applied). The Operations screen still shows the full window. Regression: the drill scenario "opens … closes — and does not flap" and the SQL check "breaker evidence after the close starts fresh". Migration 0628 was applied by the owner on 2026-10-15.
